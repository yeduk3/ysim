# Tech references

> Drop here the technical reference material the **Generator** needs but should not have to web-search for: API docs excerpts, library quirks, version-specific gotchas, internal protocol notes.
>
> One file per topic, named after the library or subsystem (e.g. `prisma-migrations.md`, `grpc-deadlines.md`).
>
> The Generator only reads files in this folder when the current slice touches the relevant area — do not put broad surveys here, put focused operational facts.
