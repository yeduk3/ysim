# FRD — Functional Requirements

> **Authored by humans.** Use this *or* `BDD.md` (or both, with FRD broader and BDD per-behavior). Pick the one that matches how the team thinks.
>
> One requirement per entry. The Planner translates these into todo items in `.agent/PLAN.md` and into matrix rows in `docs/TEST_MATRIX.md`.

## Format

```
## FR-NNN — <short title>

The system **shall** <observable behavior>.

- Trigger: <what causes this>
- Inputs: <what it depends on>
- Output: <what it produces / changes>
- Acceptance: <how we verify — usually a pointer to TESTS.md>
```
