4 invariants (enforce in code)

a · cache the KEY, never the pointer. Renderer/GUI hold the LUT name and re-lookup each frame. Rebuild re-points the entry → no dangling.
b · structural swap = paused-only. assert(paused) before destroy+recreate of CDPipeline/System. This is what makes (a) race-free.
c · no Simulator subclass. One generic Simulator. Scene specificity lives in setup*() free functions, not subtypes.
d · live state ∉ Scene. Scene = static description (topology, groups, isStatic). Live GPU pos/vel = SimState, passed per-substep.

The 5 goals

  1. Algo swap — CDPipeline is the swap unit. Researcher's choice: compose Broad+Narrow (+optional CandidateSet) OR a monolithic fused pipeline. No forced broad→narrow handoff.
  2. Unified Simulator — no Builder. setup*(Simulator&) free fn (code, fast iteration) or loadFromConfig (JSON, repro/sweep). Both write one generic Simulator.
  3. Render split — Simulator holds zero GL. Exposes render-out handles via LUT; renderer re-looks-up by name. Offscreen = null renderer = headless.
  4. Profiler — runtime level (Off/Coarse/Fine) set on Sim; export()→CSV/JSON. Runtime branch, not compiled-out.
  5. Data bus — one LUT: name→handle for render-out AND params. bind<T> typed. GUI read/write through it; dirty-policy = live | rebuild(paused) | restart-frame-0.
Attack order: build SimState + LUT seam first (render split keystone) → carve GL/GUI out of Simulator → hoist CDPipeline → System. Phasing notes on the Simulator node.
