# arch-test/DECISIONS.md

새 엔진(`arch-test/`)의 아키텍처 결정 기록. 기존 `src/main.cpp`(~20,000줄, 4700+줄 코어)는 **건드리지 않고** 별도 독립 엔진을 신축한다. 본 문서는 소유자 검토용이며, 근거는 모두 subsystem 맵에 근거한다. 코드 주석은 최소화하고 의사결정의 근거는 이 md에 남긴다.

전제(고정, 재논의 금지):
- 모든 디스패치는 **가상 인터페이스**로: `ICDPipeline`(virtual dcd/ccd), `ISystem`(virtual accumulate/integration/recoveryPenetration). `Simulator`는 `unique_ptr<ICDPipeline>` + `unique_ptr<ISystem>`를 팩토리로 선택해 보유. 컴파일타임 템플릿 디스패치 아님.
- `IBVH` 인터페이스. **karras12 LBVH가 기본 concrete**. apetrei-agglomerative / subobject-multiroot / SpatialHashing / MultiLevelSpatialHashing은 각각 별도 concrete. `BVHFactory`가 버전 + per-build-part cpu/gpu를 선택.
- `Scene` = 수동적 정적 기술(topology, groups, isStatic, materials). live pos/vel 없음. live GPU 상태는 별도 `SimState`로 substep마다 전달.
- 최소 목표: 기본 scene을 자유함수 `setupBasicScene(Simulator&)`로, GL 없는 headless `Runner`가 구동.
- 기존 `src/metal/*.metal` 셰이더는 변경 없이 재사용.
